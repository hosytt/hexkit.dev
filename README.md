## Supported Hash Algorithms

HexKit provides a variety of cryptographic hash and checksum algorithms. The following hash types are currently available:

- **BLAKE** (BLAKE, BLAKE2, BLAKE3)
- **CSHAKE** (Customizable SHAKE)
- **KECCAK**
- **KMAC** (Keccak Message Authentication Code)
- **MD** (MD2, MD4, MD5, etc.)
- **RIPEMD**
- **SHA-1**
- **SHA-2** (SHA-224, SHA-256, SHA-384, SHA-512, etc.)
- **SHA-3** (SHA3-224, SHA3-256, SHA3-384, SHA3-512)
- **SHAKE** (SHAKE128, SHAKE256)
- **SM3**
- **WHIRLPOOL**
- **XXHASH**

You can use HexKit online at: [https://hexkit.dev](https://hexkit.dev)
